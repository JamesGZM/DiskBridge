# 盘桥 · DiskBridge

把应用数据放到外置硬盘，让内置硬盘腾出空间。

盘桥是一款 **仅面向 macOS 的原生应用**，使用 Swift、SwiftUI 和 AppKit 实现管理窗口、菜单栏及后台任务。通过 APFS 稀疏镜像将外置数据挂载到应用原来的数据目录，应用本体仍留在本机。

**MIT 开源 · Apple Silicon / macOS 14+ · 无 Python 后台 · 无第三方运行时依赖**

## 下载

在 [GitHub Releases](https://github.com/JamesGZM/DiskBridge/releases/latest) 下载 ARM64 DMG 和对应的 SHA-256 校验文件。当前仅支持 M 系列芯片，不提供 Intel 安装包。

公开 DMG 不使用证书签名，也不做 Apple 公证；应用保留 M 芯片运行所需的无身份 ad-hoc 签名。macOS 可能提示无法验证开发者，请先确认下载来源和校验和，再按系统的应用打开提示自行操作。应用不使用个人证书，也不附带任何用户数据。

[Apple 关于 Apple Silicon 可执行文件签名的说明](https://developer.apple.com/documentation/macos-release-notes/macos-big-sur-11_0_1-universal-apps-release-notes)。

## 功能

| 模块 | 功能 |
| --- | --- |
| 应用管理 | 显示图标、迁移状态、数据大小、安装时间及当前目标；支持名称片段、缩写和拼音模糊搜索，按名称、大小或安装时间排序 |
| 任务管理 | 异步执行、真实字节进度、速度、等待原因、安全停止、失败恢复；已结束记录支持单条和批量清理 |
| 已迁移应用 | 包含待验收应用；提供验收、自动挂载、挂载就绪后打开、安全卸载、还原及独立原件清理 |
| 存储设备 | 异步读取容量、可用空间与连接状态，只统计当前关联应用；已还原应用和闲置磁盘历史不计入当前关联 |
| 备份与恢复 | 中断任务、待验收应用、历史原件和外置保留副本集中管理 |

菜单栏使用图标表示执行中、等待、就绪与异常；详细阶段在菜单和任务窗口查看。设置窗口可通过 `⌘,` 打开。

应用列表先显示，数据大小与磁盘信息在后台逐项更新，不等待全部扫描完成。大小指发现的可迁移数据目录占用，不含应用本体和未选共享目录；未读到的值保持未知，不能当作 0。默认按名称排列，大小按大到小、安装时间按最近优先；未知值排在末尾。安装时间优先取系统记录的添加到目录时间，否则显示应用目录创建时间，来源可在提示中查看。

数据目录按应用标识、容器、Application Support、文稿和应用声明的共享容器发现，不依赖特定应用的白名单。可以手动补充多个目录；共享目录需要单独确认。默认目标为外置盘内的 `Cache/应用名称`，支持修改。

应用目录和首屏列表分别持久缓存到本地运行目录的 `catalog.json`、`app-list.json`。重启先显示缓存，再在后台核对目录与 Info.plist 的变化，未变化的应用复用原结果；周期性核对新目录，手动刷新可强制重新扫描。大小和安装时间一起保留，但“挂载就绪”不会直接沿用缓存，必须实时核验。系统容器的 `Data/SystemData` 不参与发现，后台也拒绝迁移该目录及其子目录。

## 从源码构建

需要 macOS 14 或更新版本，以及带 Swift 5.9+ 和兼容 macOS SDK 的 Xcode 开发工具。本项目没有包依赖。

```sh
swift test
./scripts/build-app.sh
```

生成的应用位于 `dist/盘桥.app`。可以先将它放入 Applications，再从 Finder 打开。

构建脚本默认使用本地临时签名，适合开发检查。**临时签名在重新构建后可能导致系统要求重新授权**。持续使用时，请显式指定自己的固定签名身份：

```sh
DISKBRIDGE_SIGN_IDENTITY='YOUR_SIGNING_IDENTITY' ./scripts/build-app.sh
```

此变量只选择钥匙串中已有的证书；项目不会生成、保存或导出签名私钥。目前构建脚本只接受原生 ARM64 环境，并检查生成的可执行文件架构。

需要同时保留公开未签名产物和本机稳定签名时，先按默认方式构建，再执行：

```sh
swift Tools/SignLocal.swift
```

脚本只签署 `.build/local-install/盘桥.app`，不修改 `dist/`，也不导出证书或私钥。钥匙串里存在多个开发者身份时，用 `DISKBRIDGE_LOCAL_SIGN_IDENTITY` 指定证书指纹。以后本机更新持续使用同一身份签署的副本；切回公开的 ad-hoc 版本仍可能需要重新授权。可传入一个旧版本 `.app` 路径，验证不同版本的签名身份是否一致。

### 打包 DMG

```sh
./scripts/package-dmg.sh
```

安装镜像和 SHA-256 文件会生成到 `dist/`。镜像提供将应用拖入 Applications 的入口。

如需给自己的 DMG 签名，使用相同的 `DISKBRIDGE_SIGN_IDENTITY`。脚本不会自动提交 Apple 公证。公开发布工作流固定使用无身份签名，不读取个人证书。

### Actions 自动打包与发布

[Apple Silicon DMG 工作流](.github/workflows/release.yml) 在 GitHub 的 ARM64 macOS runner 上执行隐私检查、测试、构建、打包和镜像核验。

- 在 Actions 中手动运行：生成可下载的 `DiskBridge-macos-arm64` artifact，不发布版本。
- 修改 `VERSION` 和 `docs/RELEASE_NOTES.md` 后推送对应的 `v版本号` 标签：通过全部检查后自动发布 GitHub Release。
- 产物只有未签名 DMG 和 SHA-256 文件；不上传证书、配置、日志或运行数据。

例如发布新版本时：

```sh
git tag v2.0.1
git push origin v2.0.1
```

标签必须与 `VERSION` 一致。核验脚本会检查 ARM64、版本号、应用的 ad-hoc 签名、DMG 未签名状态、校验和和镜像实际内容，再允许上传。

## 使用流程

1. 打开盘桥。启动时会从后台检查权限；需要时显示引导，定位应用并打开系统设置。
2. 为盘桥开启“完全磁盘访问权限”，按系统提示退出并重新打开。应用会自动复查；设置中也有“重新检查”入口。
3. 完全退出准备迁移的应用及其其他账号窗口，选择具体的数据目录、目标硬盘和目录。
4. 查看迁移预览，确认后开始。多个目录会先全部复制和校验，再切换到外置数据卷。
5. 打开应用检查旧记录、附件和搜索，确认正常后完成验收并启用自动挂载。
6. 如需释放内置空间，**单独执行“清理原件备份”**。迁移成功不代表原件已经删除。各类备份清理均输入“确认删除”后确认，弹窗会显示应用和清理范围。

“挂载后自动打开”默认关闭。开启后每个挂载周期或开机只触发一次，主动退出应用后不会因健康检查而反复打开。

还原会将外置卷的最新数据复制回内置盘，并保留外置副本。再次迁移使用新目录；历史副本的清理仍需要独立确认。

## 数据保护与限制

- 通过文件清单和 SHA-256 校验复制结果，校验通过后才切换原目录。
- 按外置盘 UUID、镜像卷 UUID 和所有权标记核验，避免用同名磁盘代替目标盘。
- 未挂载时原路径使用不可写的空保护目录，避免应用悄悄创建新的空数据库。
- 挂载失败不会强行覆盖本地数据，不使用强制卸载。
- 自动挂载在后台启动、目标硬盘重连或相关设置开启时检查；单应用设置只检查该应用，验收成功不会再发起一次挂载。无关磁盘或安装镜像变化不会触发挂载。
- 已挂载且身份核验通过的应用直接显示就绪，不等待其他迁移释放操作锁。硬盘未就绪、应用仍运行时限时重试；其他迁移占锁时保持等待，支持安全停止。
- 清理任务记录只移除任务列表与详情，保留迁移配置、数据、原件备份和恢复所需记录；进行中的任务不能直接清理。
- 外置盘拔出前，先退出相关应用、安全卸载数据，再通过 Finder 推出硬盘。

通用目录发现不等于所有应用都兼容。应用的沙盒、共享目录、辅助进程或升级后路径变化，仍可能需要人工判断迁移范围。首次尝试请使用可恢复的数据副本。系统容器根目录、应用本体及盘桥自己的运行目录不能作为迁移对象。

稀疏镜像的逻辑容量不等于已经占用的物理空间。界面分别显示迁移数据量、原件备份和清理时实测释放空间；没有历史实测值时显示未知。

## 本地数据位置

新安装默认使用当前用户的：

```text
~/Library/Application Support/DiskBridge/
├── config.json       # 应用配置
├── state.json        # 迁移状态
├── records/          # 目录清单与校验记录
└── runtime/          # 任务、运行状态与本地日志
```

升级时会读取本机运行设置中记住的原数据目录，不将它写入源码或应用包。也可以通过 `--root` 和 `--runtime` 显式指定本地目录。不要用空配置覆盖现有迁移记录。

后台与菜单栏由同一个原生可执行文件的不同模式承担，通过本地文件交换任务。关闭窗口后任务继续；退出盘桥时可选择保留后台或在安全检查点停止。

## 测试

```sh
swift test
```

默认测试只创建临时应用和临时数据，覆盖原子写入、锁、复制校验、保护目录、确认门槛、自动打开去重、历史备份清理及数据路径兼容。

真实外置盘集成测试需要显式指定一个用于测试的可写外置盘卷 UUID：

```sh
DISKBRIDGE_TEST_VOLUME_UUID='YOUR_TEST_VOLUME_UUID' \
  swift test --filter RegressionTests.testNativeRegressionSuite
```

集成测试只在所选盘的 `Cache/.DiskBridge-Tests-*` 下建立独立夹具，不格式化硬盘，也不使用已配置应用的数据。测试会实际创建、挂载和清理临时 APFS 镜像；默认 CI 不运行这一步。

目前尚未覆盖所有硬盘、应用或整机冷启动组合；自动挂载的实际开机时序仍需在目标机器验证。

## 隐私

应用不添加遥测、不监听网络，也不会上传应用数据。通知默认关闭，由用户自行开启。

仓库不包含真实配置、聊天文件、目录清单、设备 UUID、运行日志、证书或签名二进制。公开问题中也请不要粘贴未脱敏的日志和个人路径。
