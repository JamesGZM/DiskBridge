# 盘桥 v2.0.2

完善应用管理、后台读取与本机签名流程，继续采用 MIT 协议。

## 下载与安装

- 支持 Apple Silicon（M 系列芯片），macOS 14 或更新版本。
- 下载 `DiskBridge-2.0.2-macos-arm64.dmg`，更新前退出盘桥，将应用拖入 Applications。
- 同时提供 `.sha256` 校验文件，可用 `shasum -a 256 -c` 检查完整性。

DMG 不签名、不公证；应用仅保留 Apple Silicon 运行所需的无身份 ad-hoc 签名，不使用个人或 Apple 开发证书。macOS 可能提示无法验证开发者，请先核对下载来源及校验和，再按系统的应用打开提示自行操作。

ad-hoc 签名身份可能随版本变化，升级后可能需要重新授予完全磁盘访问权限。

本机构建可使用 `swift Tools/SignLocal.swift` 生成固定开发者签名副本，位于 `.build/local-install/盘桥.app`，不修改公开产物、不导出私钥。持续使用同一签名身份更新，避免因每次构建的哈希变化而重新授权；从 ad-hoc 切换到固定身份仍需要授权复查。

## 本次修复

- 模糊搜索名称、缩写和拼音，避免所有应用因公共路径而匹配同一个字母。
- 默认名称排序；数据大小按大到小、安装时间按最近优先，新增安装时间列，移除独立升序开关。
- 应用大小与磁盘信息在后台逐项读取和更新；未发现目录显示未知，不再错误显示为零。
- 持久保存应用列表，重启即时展示缓存并后台增量核对，不再每次从空列表开始；挂载就绪状态仍实时验证。
- 补全厂商目录、带版本的数据目录和应用容器内数据的通用发现规则。
- 排除并拒绝迁移系统容器的 `Data/SystemData`，防止系统管理数据被误选。
- 已还原应用显示本机位置，不再计入外置盘当前关联；不显示闲置历史恢复卷。
- 已结束任务支持单条及批量清理；备份确认短语统一为“确认删除”。
- 已挂载应用不因其他迁移持锁而误报等待；验收不再触发全部自动挂载。

## 功能

- 应用列表、图标、搜索筛选与迁移状态；支持多个数据目录的预览、复制与 SHA-256 校验。
- 后台任务、字节进度、等待原因、安全停止、失败恢复和历史记录。
- 独立自动挂载与挂载后打开设置、菜单栏图标状态、启动权限检查与引导。
- 存储设备容量与关联应用、独立原件清理、还原及历史副本管理。

## 数据与限制

新安装使用当前用户的应用支持目录；已有本地运行设置可继续指向原迁移记录。不要用空配置覆盖旧记录。安装包不包含个人配置、聊天数据或日志。

首次迁移请使用可恢复的数据副本，并在应用内检查后验收。通用目录发现不保证所有应用都兼容。未覆盖所有硬盘与整机冷启动组合。本次不提供 Intel 版本。
