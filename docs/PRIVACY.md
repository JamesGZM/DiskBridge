# 公开源码与隐私

公开仓库只包含项目代码、合成测试夹具和文档。应用在本机生成的配置、目录清单、路径、日志和任务结果不属于公开内容。

## 不应提交的内容

- `config.json`、`state.json`、`records/`、`runtime/`、`logs/`。
- 聊天数据、账号名称、真实设备 UUID、个人目录或带个人内容的截图。
- 证书、私钥、钥匙串导出文件、签名身份文件或环境变量文件。
- 由个人证书签名的应用或 DMG；签名证书本身可能含有姓名、邮箱或团队标识。
- 含有本机编译路径、签名信息或个人文件内容的构建产物。

`.gitignore` 会排除常见本地产物，但不能代替人工检查。提交前运行：

```sh
swift Tools/PrivacyCheck.swift
git diff --cached --stat
git diff --cached
```

检查脚本扫描已跟踪文件中的常见个人路径、邮箱、设备 UUID、凭据及禁止发布的文件类型；结果只报告文件、行号与类别，不打印匹配内容。它不能保证识别所有个人信息，尤其不能识别图片中的隐私。

## Git 元数据

Git 提交也会公开作者、提交者和邮箱。可在当前仓库设置项目署名或使用 GitHub 的 noreply 邮箱，避免沿用本机的私人邮箱。设置只影响后续提交，已有历史中的身份不会自动改变。

参考：[GitHub 提交邮箱说明](https://docs.github.com/en/account-and-profile/how-tos/email-preferences/setting-your-commit-email-address)。

GitHub 公开仓库的所属账号及公开活动仍然可见。项目不能隐藏 GitHub 平台本身已经公开的账号信息。

## 本机行为

盘桥会在本机发现应用、核对目录和校验文件。相关元数据保存于用户自己的应用支持目录，不上传到服务端。权限开关由系统管理；应用不会自动获取完全磁盘访问权限。

提交问题时请仅提供复现步骤和必要的脱敏摘要，不上传完整聊天数据库、原始校验清单或未经检查的运行日志。
